# Rider Stretch

Scheda settimanale di stretching e mobilità per palestra, snowboard, wakeboard, surf e skate: esercizi illustrati con spiegazioni, scelta di giorni, minuti e durata, timer guidato.

**App:** https://frankojib.github.io/Stretching-franko/

## Installarla sul telefono

1. Apri il link con Chrome.
2. Menu (tre puntini) → **Installa app** oppure **Aggiungi a schermata Home**.
3. Dopo la prima apertura funziona anche senza connessione.

Progressi e impostazioni restano salvati sul dispositivo che usi.
